# Hammerless's own descriptions of L4D2's script functions, and names for their inputs.
# One line per function:  id | input names, comma separated | description
# An input written "Name=table" takes a table (or list) of values, "=fills" is a table the function fills
# in: it isn't an input; the node gives the filled table as its Result instead.
# The thing a method acts on (player / entity / nav area) is its first socket and isn't listed here.
