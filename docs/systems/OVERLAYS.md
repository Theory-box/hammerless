# Brush overlays

Add **Brush Overlay** from the Hammerless Add panel or Shift+A > Hammerless. It starts at the nearest brush surface to the 3D cursor, automatically aligned. Use **Align to Nearest Brush** to realign an existing overlay. Local +Z points outward from the receiving surface. Width and Height use Hammer units; normal object move/rotate/scale work too.

The selected object's **Decal Browser** shows thumbnails from game materials with decal/overlay in their path. Search filters these names; Search All Materials includes other texture paths. Click a thumbnail's name to replace the overlay material without recreating it.

The overlay projects onto nearby, forward-facing world and detail brush faces. It spans brush seams without shrinkwrapping. Receiver Depth searches from the empty toward local -Z, selecting whole faces whose projected footprint intersects that forward range. Surfaces entirely behind the emitter (+Z) are excluded. Crossing the depth boundary does not trim the selected footprint: Source exports a face list and has no depth-clipping parameter. This keeps tilted overlays attached to a receiver. Select brushes along with the overlay, keep the overlay active, and use Assign Selected Brushes to restrict projection. All Nearby clears that restriction. Imported brush objects do not currently have reliable name mapping for assigned-brush filtering; use All Nearby for them.

The first version excludes terrain, props and moving brush entities. There are no saved preview meshes and no extra bake/collision geometry. The GPU preview pauses during compilation and baking. Texture caches drop unused preview materials on rebuild and clear on load/undo/redo. Shared thumbnail caches follow the existing material browser's lifetime.

Export resolves the receiving side IDs from the final written brushes, including auto-detail conversion, and emits a native `info_overlay`. No nearby face is an export error. Large overlays may exceed Source's compiled-face limit, even if the original brush-side count is below the limit; reduce their footprint if the compiler reports this. Existing imported raw overlays are not converted into authored overlay controls.

Projection and export use the same rectangle clipping and face-selection rules. Alpha, additive and DecalModulate (multiply) previews are supported. Ordinary lightmapped decal shading is approximate in the viewport; material effects such as bump/detail maps, transforms, tint and material proxies are not fully reproduced. The native game material is exported unchanged. The panel reports known unsupported shader/parameter cases. Do not treat this first preview as pixel-identical lighting or as a verified in-game UV orientation comparison.

Validation: pure projection/export tests cover seams, slope, depth boundaries, backface and tools rejection, face IDs, and world/detail conversion. Background Blender smoke covers registration, creation, transform extraction, alignment and VMF export. A generated Blender overlay compiled with both compilers has byte-identical overlay/fade/system-level lumps. The generated fixture also exposes an unrelated existing brush smoothing-bit difference in the faces lump. Existing overlay compiler fixtures pass. No game launch or visual in-game comparison was performed for this feature.

Preview performance: receiver geometry is cached independently of projectors. Collection transform notifications do not discard it; actual receiver geometry changes do. Receiver membership/visibility is checked on preview rebuild. A vectorized bounds pass limits polygon clipping to nearby faces. Regression coverage uses an organized map collection, which emits extra collection notifications on projector transforms.

**Stop at Surface** defaults on, including existing authored overlays without a saved value. It compares nearby projected brush polygons and excludes faces occluded by nearer receiving faces; disjoint faces and coplanar seams remain supported. Because native Source overlays store whole side IDs, a partially occluded receiving face is conservatively excluded as a whole. This is not pixel-level clipping, and brush material alpha is not evaluated for occlusion. Disable the toggle for the previous multi-layer projection. Preview and VMF export share the same filter; no map geometry is split.

Release 0.20.25: receiver conversion is cached per object. Transforms outside all active projection bounds discard stale per-object geometry for later without scheduling a preview rebuild; old and new bounds are checked to catch entering/leaving receivers. Material changes invalidate only dependent objects. Assigned receivers are scoped to collection-instance source labels during export.
